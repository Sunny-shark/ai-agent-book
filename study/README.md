# AI Agent 学习档案

本目录记录我学习《深入理解 AI Agent》及复现配套项目的过程。源码实验仍保留在仓库原有的 `chapter1` 至 `chapter10` 目录；这里集中保存每章的实验记录、问题排查过程和阶段性学习总结。

## 使用方式

每章学习时：

1. 在对应章节目录下为每个实验新建子目录，并记录环境、命令、结果、问题与解决过程。
2. 保存可公开的复现实验结果；API Key、`.env`、订阅链接和其他凭据不提交。
3. 学完一章后，补充该章根目录的 `README.md`，总结核心概念、实验结论、局限和后续问题。

新章节可复制 [章节模板](chapter-template.md)。
